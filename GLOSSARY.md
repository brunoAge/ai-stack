# AI stack

Bruno's personal AI coding stack: the repo defines it, and each computer holds an installed copy.

## Language

**Repo**:
The definition of the stack.
_Avoid_: machine, the other PC

**Machine**:
One computer's installed copy of the stack.
_Avoid_: repo, stack

**Stack**:
The set of pieces the repo says a machine has.
_Avoid_: user rules, and skills the repo does not define

**Workflow preferences**:
The always-on rule that assigns a model to the parent chat and to each role, and sets the third-party budget for a task.
_Avoid_: model-slots, model rule

**Role**:
A named kind of subagent whose model comes from the workflow preferences.
_Avoid_: slot, agent file
